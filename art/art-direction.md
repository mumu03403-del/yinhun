## 1. 动漫还原调性定义

目标：让玩家一眼感受到"这就是日式动画的味道"，但不依赖任何单一作品的美术资产。

| 维度 | 定义 | 通用参考（非特定 IP） |
|------|------|----------------------|
| **描边线** | 清晰黑色勾线，外轮廓约 2.5–3px（1080p 设计稿基准），内部细节线 1.5–2px；线端收口干净，无半透明柔化 | 传统赛璐珞动画 / JUMP 系少年漫画的硬边勾线 |
| **上色（赛璐珞平涂）** | 大色块平涂，每区域 2–3 个明度层级（高光 / 中间调 / 阴影），**明暗边界明确**，避免柔化渐变；仅在皮肤/金属处保留极窄过渡 | 经典 TV 动画数位上色（Cel-shading） |
| **比例** | 成人角色约 6–7 头身；少年向角色约 5–5.5 头身；Q 版占位用 2.5–3 头身 | 通用日式动画人体比例 |
| **五官与表情** | 眉眼对比强、瞳孔高光明显；表情可夸张（挑眉、咧嘴、汗滴）以增强喜剧感 | 典型喜剧向动画表情语言 |
| **构图与动态** | 角色姿态略带夸张张力，重心偏移制造动感；背景用简笔市井/街景色块衬托烟火气 | 日常喜剧动画的镜头节奏 |
| **整体氛围** | 明亮、高饱和主色 + 少量冷色（蓝/青）做对比；诙谐轻松，带"下町/市井"的温度感 | 都市日常 + 无厘头喜剧混合调性 |

**调性一句话**：干净硬边勾线 + 平涂赛璐珞 + 夸张表情 + 高饱和市井暖调。

## 2. 原型期占位资产策略

目的：用最低成本跑通玩法，同时把 IP 风险隔离在"占位层"。

**占位原则**

1. **原创优先**：所有占位角色一律采用**原创 Q 版 + 纯色块**绘制，不出现任何近似既有角色的轮廓、发型、服装标识。
2. **色块占位法**：
   - 角色 = 圆形头 + 矩形/梯形身体 + 1–2 个表情符号（如 `^_^` / `>_<` / `T_T`）。
   - 道具/合成物 = 单色圆角矩形 + 图标化符号（★ ◆ ● 等），用色相区分种类。
3. **命名隔离**：占位文件与代码内一律使用 `placeholder_*` / `char_tmp_*` 前缀，禁止出现 IP 相关命名。
4. **醒目标注**：在资产预览页与 README 顶部固定标注：
   > 🚫 占位资产为原创临时素材。**正式上线需取得动漫 IP 授权，或改为完全原创角色。**

**占位规格（原型）**

| 资产类型 | 推荐尺寸（@2x） | 格式 | 备注 |
|----------|----------------|------|------|
| 角色立绘占位 | 600 × 800 px | PNG（透明底） | Q 版 3 头身色块 |
| 卡牌缩略图 | 300 × 400 px | PNG | 由立绘裁切 |
| 合成道具图标 | 200 × 200 px | PNG | 圆角矩形 + 符号 |
| 背景占位 | 1080 × 1920 px | JPG | 2–3 色块渐层即可 |

**替换路径**：原型验收后，按"已授权 IP 美术"或"原创美术"两套管线之一，整体替换 `placeholder_*` 资产，无需改动 UI 框架。

## 3. 角色卡牌 UI 规格

面向手机竖屏（基准 375 × 812 pt，@2x / @3x），保证单手可读。

**卡牌本体**

- **比例**：3 : 4（宽:高），单卡视觉宽度约占屏宽 1/3。
- **推荐资源尺寸**：600 × 800 px（@2x），@3x 用 900 × 1200 px。
- **圆角**：16 pt；**外描边**：4 pt，颜色随稀有度变化（见下表）。
- **内部分区**：
  - 顶部 18%：稀有度星标 + 角色名条（半透明深色底）。
  - 中部 62%：立绘展示区（留白边距 12 pt）。
  - 底部 20%：等级/战力数字条 + 元素/职业小图标。

**网格布局**

- 默认 **3 列**，间距 12 pt；窄屏可降为 2 列。
- 列表滚动保留底部操作栏（合成/出战按钮）常驻。

**稀有度配色方案（Rarity Color）**

| 稀有度 | 标识 | 边框/光效色 | 底色倾向 | 说明 |
|--------|------|------------|----------|------|
| N  | ★ | `#9AA0A6` 灰 | 中性灰白 | 常见，无光效 |
| R  | ★★ | `#4CAF50` 绿 | 浅绿灰 | 轻微描边光 |
| SR | ★★★ | `#3F7BFF` 蓝 | 冷蓝灰 | 蓝色描边 + 微光 |
| SSR| ★★★★ | `#FFB300` 金 | 暖金白 | 金色动态光效 + 星点 |

> 配色在灰阶下仍需可区分（避免仅靠色相），可叠加★数量与圆点密度辅助辨识，照顾色弱用户。

**可读性要求**

- 角色名/数字文字 ≥ 24 pt（@1x），正文 ≥ 22 pt。
- 文字与底色对比度 ≥ 4.5:1（WCAG AA）。
- 立绘主体避开底部文字区，防止遮挡。

## 4. 配色与字体

**整体调色板（Palette）**

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 Primary | `#FF6B6B` 暖珊瑚红 | 主按钮、强调、品牌色 |
| 辅色 Secondary | `#FFD166` 暖黄 | 次级按钮、奖励、高亮 |
| 背景 Background | `#FFF7EC` 米白 / `#2B2530` 深紫灰（夜间） | 页面底色 |
| 面板 Panel | `#FFFFFF` / 深模式 `#36303D` | 卡片、弹窗底 |
| 文本 Text | `#2B2530` 深 / `#F5F0E6` 浅 | 正文 |
| 成功/合成 | `#4CAF50` 绿 | 合成成功、增益 |
| 警示 | `#E5564E` 红 | 错误、冷却 |

> 原则：暖色主导（符合"市井烟火/喜剧"），冷色仅作稀有度与信息对比点缀；保持整体高明度、中高饱和。

**字体建议（Font）**

- **中文正文/标题**：优先系统圆体，降低棱角、贴合休闲动漫感——
  - iOS：`PingFang SC`（Round 观感）
  - Android：`Source Han Sans / 思源黑体`（或厂商圆体如 OPPO Sans、vivo 字体）
  - 备选 Web 安全：`"Noto Sans SC"`
- **数字 / 战力 / 等级**：使用**等宽数字字体**（如 `DIN` / `Roboto Mono` / 系统 `SF Mono`），保证卡牌数值对齐、跳动时不抖动。
- **美术字体（标题/活动）**：可引入一款**圆体或手写感**展示字体（需确认商用授权），仅用于大标题，正文禁用花体以保证可读。
- **字号阶梯**：标题 32–40 pt，副标题 28 pt，正文 22–24 pt，辅助 18–20 pt（均 @1x）。
