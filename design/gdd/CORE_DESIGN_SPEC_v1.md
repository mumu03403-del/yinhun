## 2. 核心循环定稿

### 2.1 一句话循环

> **免费征兵 → 拖动合并升阶 → 点亮图鉴 → 盘面挂机产金 → 金币扩格 / 买兵 / 升星 → 盘面更强、更满、更高档 → 回到征兵。**

### 2.2 拆解

| 阶段 | 玩家动作 | 系统反馈 | 情绪目标 |
|---|---|---|---|
| ① 生成 | 点「招募」，或花金币直购 | 棋盘随机空格出现 1 个 1 档单位 | 零门槛、随时有事做 |
| ② 合并 | 拖动/点选两个**同档**单位 | 升 1 档 + 一次性金币奖励 + 闪光/飘字 | **核心爽点**：即时的「变大」反馈 |
| ③ 图鉴解锁 | 首次产出某档位（自动） | 第 N 张卡由剪影变亮，图鉴进度 +1，**全局产金 +5%** | **长线爽点**：收集与「我变强了」 |
| ④ 挂机产金 | 无需操作 | 盘面所有单位按档位每秒产金，HUD 实时跳动 | 放下手机的踏实感 |
| ⑤ 消费回流 | 花金币 | 扩格 / 买兵 / 图鉴升星 | **目标感**：金币永远有下一个去处 |
| ↺ 回到 ① | — | 棋盘更大、单位更多更高档 → 产金更快 | 闭环加速 |

### 2.3 设计原则（约束后续所有设计）

1. **单货币**：只有金币。不做钻石、不做体力。减少一次理解成本。
2. **产金来自盘面，不来自图鉴**：挂机收益 = 棋盘上单位的产金之和。图鉴只提供**全局倍率**，不叠加第二套产金源——**这是防通胀的第一道闸**（见 §5）。
3. **金币永远有下一个去处**：至少保留一个**成本指数递增、无购买次数上限**的出口（金币直购单位），作为货币压力阀（见 §5.3）。
4. **零操作也能变强，但操作能明显加速**：放置是底盘，合并是加速器。

### 4.2 挂机产金公式 —— **本文件的第一个关键定稿**

**定稿：采用工程实际生效值 `coinRate = 3^(tier-1)`，废弃旧概念稿的 `1 × 1.8^(tier-1)`。**

| tier | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 产金/秒 | **1** | **3** | **9** | **27** | **81** | **243** | **729** | **2187** |

**理由（三条）**：

1. **它已经跑在代码里**。`GameConfig.coinRate = [1,3,9,27,81,243]` 是唯一有代码依据的曲线，改设计比改代码便宜，且不引入回归风险。
2. **它更符合放置类的「后期爽感」需求**。底数 3 与底数 1.8 的差距是**指数级的**：tier 8 时 2187/s vs 33/s，差 66 倍。放置品类后期的核心快感来自「数字爆炸」，1.8 的曲线在 8 阶后偏「温吞」。
3. **旧公式的唯一优势是「好控制」，但这个优势可以用回收出口补回来**。3 的底数确实会带来中期通胀压力，因此本规格**强制配套 §5 的出口设计**，把「增速快」变成「你必须给钱找去处」的设计约束，而不是失控风险。

**配套强制条款**：采用 `3^(tier-1)` 的前提是 §5 的三个金币出口必须同步落地；**只做公式不做出口 = 货币失能，视为设计未完成。**

### 4.3 产出与消耗数值表

价格基准单位 `U = 3^(H-1)`，`H` = 玩家**历史最高档位**（1–8，只升不降）。
**所有大额消耗锚定 `U`**，与产出同阶指数上涨——这是防中期通胀的核心机制。

| 参数 | 公式 / 定稿值 | 依据 | 估算/实测 |
|---|---|---|---|
| 挂机产金 | `coinRate(tier) = 3^(tier-1)` /秒，盘面求和 | 见 §4.2 定稿 | **实测**（代码） |
| 结算粒度 | 在线 1 秒 / 离线 60 秒 | 沿用原型 1s tick；离线按分钟粒度降低计算量 | 在线 = 实测 / 离线 = 估算 |
| **合并奖励** | `mergeReward(N) = 5 × 3^(N-1)`（合成出 tier N 时一次性给）<br>tier2 = 15，tier5 = 405，tier8 = 10,935 | 与挂机公式**同底数**，避免两套曲线打架；量级 ≈ 该档**单单位 5 秒产出**，手感上「合一下就有收获」 | **估算** |
| **免费招募冷却** | **8 秒** | 堵住「免费无限招募」漏洞（原型当前 0 冷却、无上限，等于产金无上限） | **估算** |
| **金币直购单位**（← 无上限压力阀） | `cost(k) = 20 × 1.08^k`，`k` = 本局累计直购次数<br>k=0 → 20；k=50 → 938；k=100 → 43,980；k=150 → 2.0M；k=200 → 96.8M | ① 让金币**直接兑换时间**（跳冷却）；② `1.08` 使第 200 次购买 ≈ D7 玩家一天产出，**边际成本永远追得上产出**；③ **无次数上限 = 无限吸收金币**，是货币体系的压力阀 | **估算** |
| **扩格成本** | 第 n 格（n = 21…30）：`cost = 5000 × U × 1.6^(n-20)`<br>单次全开 10 格总量 = `907,925 × U` | 与产出同阶指数；`1.6` 递增速度温和，避免第 10 格直接劝退 | **估算** |
| **图鉴解锁倍率** | 每解锁 1 张卡 → **全局产金 +5%**；倍率封顶 **+150%** | 让图鉴有**机制价值**（不只是看图），同时封顶防止无限叠加成第二套通胀源 | **估算** |
| **图鉴升星** | 单卡第 s 星（s = 1…5）：`cost = 1000 × U × 3^(s-1)`<br>单卡升满 = `121,000 × U`；8 卡全升满 = `968,000 × U` | 中/长期大额出口，给「钱多到没处花」的阶段一个明确目标 | **估算** |

## 5. 经济健康度自检

### 5.1 测算模型（假设全部明示）

- **有效产出时长/日 = 6 小时 = 21,600 秒**
  = 在线 2h（100%）+ 离线 22h 但受 8h 封顶 × 50% = 4h 等效
- 棋盘格数：D1–D2 = 20 格 / D3–D5 = 25 格 / D6+ = 30 格

### 5.3 出口能力 vs 产出

| 出口 | D1（H=3, U=9） | D3（H=4, U=27） | D7（H=5, U=81） |
|---|---|---|---|
| 扩格（20→30 全开） | 8.17M | 24.5M | 73.5M |

| **一次性出口小计** | 16.9M | 50.6M | 151.9M |
| **一次性出口 / 当日产出** | **4.3×** ✓ | **3.5×** ✓ | **2.9×** ✓ |

### 5.4 结论与对冲

**结论 1：7 天内不会出现失控通胀。**
一次性出口总量（151.9M @ H=5）与 7 日累计产出（164M）同量级，且金币直购单位作为无上限压力阀可以吸收任意金额。**货币在整个 7 天窗口内都有下一个去处。**

**结论 2：真正的风险不是「通胀」，而是「货币失能」（D14+）。**
一次性出口（扩格 10 格、升星 5×8 星）会被买完，之后只剩金币直购单位一个出口。而直购单位的吸收效率是 O(log)——日产出涨 13 倍（3.9M → 52.5M），能买次数只从 125 涨到 158，**玩家的金币会开始堆积在账上，货币失去意义**。

**对冲设计（按落地优先级）**：
1. **v1 必做**：金币直购单位无上限（压力阀）——保证任何阶段都不「钱花不出去」。
2. **v1 必做**：所有大额消耗锚定 `U = 3^(H-1)`——玩家爬档位时，出口价格同步上涨，不会出现「一档通吃」。
3. **v1.5 建议**：周期性可重复出口（每日刷新的「限时外观 / 棋盘皮肤 / 拖拽特效」轮换商店），把散钱沉淀为收集品。这是 `art-direction.md` 视觉调性的天然延伸，**且不增加玩法复杂度**。
4. **后续**：广告加速类消耗（跳冷却、离线 ×2）——既是出口又是变现，一举两得（FRD §7 场景表可直接复用）。

**结论 3：早期（D1）刻意留盈余是可接受、且被推荐的。**
新手期让玩家「钱够用、想买就买」，换取低挫败的上手感，比精算平衡更重要。压力阀的存在保证了盈余不会变成负担。

## 6. IP 处置方案（业务级，需老板拍板）

### 6.1 问题定性

原型使用了**银魂（Gintama）**题材（文件名、`package.json` 名、文档标题、占位角色名均带 IP 味）。
版权归属：原作 空知英秋 / 集英社；动画 SUNRISE（Bandai Namco Filmworks）。
**商业公开发布（微信小游戏上线、投放、变现）中使用其角色名、立绘、台词、IP 元素 = 侵权高风险，构成上线硬阻断。**

**处置方向：完全去 IP 化，改为原创 IP 合并放置**（另一条路「取得正规授权」成本高、周期长，且本作体量不匹配，不推荐）。

### 6.2 三个原创替代题材候选

> 共同要求：保留「动漫还原」视觉调性 + 「合并进化链 + 图鉴收集」玩法骨架；无任何擦边命名；每阶形态可辨识、可简化成占位色块。

---

#### 候选 A：《和果子进化录》—— 和风点心精灵

- **题材一句话**：把街角一间老和果子铺里的甜点精灵，从「一粒糖霜」逐步养成「铺主的守护神」，陪一条老街复苏。
- **进化链（1 → 8 阶）**：
  `糖霜粒` → `串团子` → `草莓大福` → `铜锣烧` → `花见团子串` → `抹茶羊羹` → `三色最中` → `金箔献上菓子`
- **目标用户吸引力**：女性休闲玩家、治愈系偏好者、和风文化爱好者。**收集驱动 + 装扮驱动**双重命中，微信小游戏该人群占比高、广告观看意愿与外观付费意愿都更强。
- **美术工作量粗估**：**中（最低）**。全部物件有现实参照且形态圆润简单，8 阶造型差异天然明显（粒 → 串 → 包 → 饼 → 串 → 块 → 方 → 华丽礼盒）。Q 版拟人化只需「圆头 + 物件身体 + 2 个表情符号」，与 `art-direction.md` 的占位色块法**完全兼容**。粗估 1 线 8 张立绘 + 8 图标；若做 3 线则 24 + 24。
- **风险**：① 和风甜点题材在小游戏赛道已有同类产品，**差异化必须靠「进化链 + 图鉴」而非题材本身**；② 需注意不出现任何具体店铺品牌或既有作品标志。

---

#### 候选 B：《夜灯街的守夜人》—— 都市灯火小妖

- **题材一句话**：收集并进化一整个「灯火」家族，用光点亮一条逐渐复苏的深夜老街。
- **进化链（1 → 8 阶）**：
  `火星子` → `小油灯` → `纸灯笼` → `走马灯` → `街口路灯` → `灯台精灵` → `月轮灯` → `长明灯神`
- **目标用户吸引力**：偏「都市怪谈 / 妖怪」调性的二次元玩家，神秘感 + 守护感，男女通吃；「点亮老街」的叙事钩子能撑起长线目标感。
- **美术工作量粗估**：**中高**。8 阶需要「光」的表现（发光、飘动、粒子），发光材质在微信小游戏上有**性能成本**，且占位色块法较难传递「光」的质感，占位阶段与正式阶段的**观感落差较大**。
- **风险**：① 暗色调与「轻治愈」定位有偏移，与 `art-direction.md` 的「高饱和市井暖调」需要额外调和；② 妖怪题材易与既有日本作品产生**联想风险**，命名需严格回避「猫又 / 河童 / 天狗」等高频既有元素。

---

#### 候选 C：《发条星球》—— 萌系机械造物

- **题材一句话**：从一颗螺丝开始，把一枚小卫星逐级拼装成能承载整个星球的方舟。
- **进化链（1 → 8 阶）**：
  `螺丝` → `齿轮组` → `发条盒` → `小马达` → `侦察无人机` → `机械兽` → `轨道方舟` → `星环巨构`
- **目标用户吸引力**：中性偏男性向，「科技美学 + 收集」的组合在小游戏赛道相对稀缺，能吃到一批不买「可爱甜点」账的玩家。
- **美术工作量粗估**：**高**。机械结构细节多、8 阶造型跨度大，绘制成本高于圆润物件；虽然可用「几何体 + 发光描边」降本，但**视觉丰富度会明显打折扣**。
- **风险**：① 微信小游戏该题材受众偏窄，**DAU 天花板可能低于 A**；② 「可爱 + 机械」调性难平衡，处理不好易显得冷硬，与「轻治愈」的加分项相悖。

### 6.3 推荐项与理由

> **推荐：候选 A《和果子进化录》（和风点心精灵）**

理由（按权重排序）：

1. **与既有美术方向 100% 契合**。`art-direction.md` 定义的是「干净硬边勾线 + 平涂赛璐珞 + 夸张表情 + **高饱和市井暖调**」——暖色主导、圆润造型、市井烟火气。和果子是**唯一同时满足「暖色 + 圆润 + 市井」三条**的候选，不需要为题材回头改美术方向。
2. **占位 → 正式美术的迁移成本最低**。形态简单圆润，用「色块 + 符号」做占位时，玩家仍能一眼看出「这是个团子」，占位期体验不会崩。这是三个候选里唯一能做到这一点的。
3. **目标人群与小游戏商业化路径一致**。女性休闲用户的激励视频观看意愿与外观兑换意愿都更高，直接决定后续变现效率。
4. **零 IP 风险**。「和果子」是一个**食物品类**，不属于任何主体，不存在擦边命名空间；只要不出现具体店铺品牌或既有作品标志即可。
5. **8 阶进化链自带动线**：粒 → 串 → 包 → 饼 → 华丽礼盒，形态递进可辨识，天然具备「我想看看下一阶长什么样」的驱动力，正好喂给「合并 + 图鉴」这个骨架。

**次选**：候选 C（若老板明确希望避开和风、走差异化科技向）。
**不推荐**：候选 B（发光材质的性能成本 + 调性偏离，性价比最低）。
